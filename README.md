# Lumen Isle

A peaceful, procedural 3D miniature island, built with Three.js and Vite. No model downloads or API keys are needed.

## Run locally

```sh
npm install
npm run dev
```

Open the local URL printed by Vite. To create a production build, run `npm run build`; serve it with `npm run preview`.

## Explore

- Drag to orbit; scroll or pinch to zoom.
- Right-drag or two-finger drag to pan.
- Select one of four landmarks to move the camera and discover it.
- Use the toolbar to reset, auto-rotate, or switch between daylight and golden hour.
- Arrow keys orbit, `+` / `-` zoom, and `H` returns home when focus is outside a button.

The scene supports touch, reduced-motion preferences, and responsive layouts. WebGL is required. Interface fonts load from Google Fonts, with local sans-serif fallbacks.
